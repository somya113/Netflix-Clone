# Netflix Clone

A beautifully designed Netflix clone built with HTML, CSS, and JavaScript. This project replicates the core user interface of Netflix, including the profile selection screen and the main browsing interface.

## Features

- **Profile Selection Screen**: A fully functional landing page that prompts the user to select their viewing profile.
- **Main Dashboard**: A sleek and responsive main page featuring a hero section, navigation bar, and categorized rows of movies/shows.
- **Interactive UI**: Hover effects, responsive SVGs, and modern CSS styling to mimic the real Netflix experience.

## Technologies Used

- **HTML5**: Semantic structure.
- **CSS3**: Custom styling, Flexbox, Gradients, SVG manipulation, and Hover animations.
- **JavaScript (Vanilla)**: DOM manipulation and interactivity.
- **FontAwesome & Google Fonts**: Icons and typography (Bebas Neue).

## Local Development

1. Clone this repository:
   ```bash
   git clone https://github.com/somya113/Netflix-Clone.git
   ```
2. Open `1st_page.html` in your web browser to start from the profile selection screen, or `2nd_page.html` to view the main dashboard.

## Deployment

This project is configured to be easily deployable on **Vercel**. 
Simply connect your GitHub repository to Vercel, and it will automatically deploy the site using the included `vercel.json` configuration to route the root URL to the profile selection screen.
